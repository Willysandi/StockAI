# 📈 ASX Stock Dashboard

Ask questions about ASX stock performance in plain English. Claude AI converts your question into SQL, runs it against a PostgreSQL database of historical stock data, and explains the results back to you with charts.

## How it works

```
User question (plain English)
        │
        ▼
Claude AI ──► generates SQL ──► PostgreSQL (asx_stocks table)
        │                              │
        ▼                              ▼
Claude AI ◄── query results ◄── safe SELECT-only execution
        │
        ▼
Streamlit dashboard: insight + data table + price chart
```

1. You type a question like *"Which stock had the biggest single-day price drop this year?"*
2. Claude converts it to a SQL query against the `asx_stocks` table
3. The query runs against PostgreSQL (SELECT-only queries are enforced)
4. Claude analyses the results and writes a short financial insight
5. Streamlit displays the insight, the generated SQL, a formatted data table, and a price chart

## Stocks tracked

BHP, CBA, CSL, NAB, WBC, ANZ, WES, MQG, RIO, TLS (daily OHLCV data via Yahoo Finance)

## Project structure

| File | Purpose |
|---|---|
| `app.py` | Streamlit dashboard UI |
| `claude_query.py` | Claude integration: question → SQL → results → insight |
| `database.py` | Creates the `asx_stocks` table and loads/updates data from Yahoo Finance |
| `mcp_server.py` | MCP server exposing the database as a `query_asx_stocks` tool (e.g. for Claude Desktop) |
| `requirements.txt` | Python dependencies |

## Setup

### 1. Clone and install dependencies

```bash
git clone https://github.com/<your-username>/databaseASX.git
cd databaseASX
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux
pip install -r requirements.txt
```

### 2. Configure environment variables

Create a `.env` file in the project root:

```env
ANTHROPIC_API_KEY=your-anthropic-api-key
DATABASE_URL=postgresql://user:password@host:5432/dbname
```

- Get an Anthropic API key at [console.anthropic.com](https://console.anthropic.com)
- `DATABASE_URL` can point to any PostgreSQL instance (local, Supabase, Neon, etc.)

If deploying to Streamlit Cloud, set the same two values in **Streamlit secrets** instead.

### 3. Create the table and load stock data

```bash
python database.py
```

This creates the `asx_stocks` table (if it doesn't exist) and downloads daily price data for all tracked tickers. Re-run it any time to fetch the latest prices — it only inserts dates that are missing.

### 4. Run the dashboard

```bash
streamlit run app.py
```

Open http://localhost:8501 and start asking questions.

## Example questions

- Which stock had the highest closing price last month?
- What is the average closing price of BHP.AX over the past 3 months?
- Which stock had the biggest single-day price drop this year?
- Compare the closing prices of CBA.AX and NAB.AX over the last 30 days
- Which stock has the highest average trading volume?

## MCP server (optional)

`mcp_server.py` exposes the database as an [MCP](https://modelcontextprotocol.io) tool so Claude Desktop (or any MCP client) can query it directly. Add this to your Claude Desktop config:

```json
{
  "mcpServers": {
    "asx-stocks": {
      "command": "python",
      "args": ["C:/path/to/databaseASX/mcp_server.py"]
    }
  }
}
```

## Database schema

```sql
CREATE TABLE asx_stocks (
    id     SERIAL PRIMARY KEY,
    ticker VARCHAR(20),
    date   DATE,
    open   NUMERIC,
    high   NUMERIC,
    low    NUMERIC,
    close  NUMERIC,
    volume BIGINT,
    UNIQUE (ticker, date)
);
```

## Safety

Only `SELECT` queries generated by Claude are executed — anything else is rejected before it reaches the database.
